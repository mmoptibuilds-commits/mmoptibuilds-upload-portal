# Design system

The interface uses a 60/30/10 visual-weight system: Stealth Black is the environment, Graphite/Steel form structural surfaces, and Optiblue, Tech Teal, and Performance Orange communicate action and state. Spacing is based on 4, 8, 12, 16, 24, 32, 48, and 64. Controls use 4–8px radii; panels use 12–16px; high-attention completion uses 24px.

Depth is consistent: black environment, graphite base plane, steel interactions, dark-glass overlays, then transient feedback. Blue is reserved for secure action/progress/focus; teal is healthy/ready; orange is attention; green/yellow/red are semantic states. Text and focus colors were selected for dark-surface contrast and all interactive controls retain a visible focus indicator.
